## 🚀 Quick Start

```bash
# Backend
cd backend
python -m venv venv
venv\Scripts\activate  # or: source venv/bin/activate
pip install -r requirements.txt
python main.py

# Frontend (New Terminal)
cd frontend
npm install
npm run dev

# Open Browser
http://localhost:3000
```
