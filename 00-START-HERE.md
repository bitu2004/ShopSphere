## 🚀 **GET STARTED IN 60 SECONDS**

### Copy & Paste These Commands:

**Terminal 1:**
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn main:app --reload
```

**Terminal 2:**
```bash
cd frontend
npm install
npm run dev
```

**Browser:**
```
Open: http://localhost:3000
```
