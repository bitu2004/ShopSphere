## 🚀 Start in 5 Minutes

### Windows
```powershell
# Terminal 1
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py

# Terminal 2
cd frontend
npm install
npm run dev

# Browser: http://localhost:3000
```

### macOS/Linux
```bash
# Terminal 1
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py

# Terminal 2
cd frontend
npm install
npm run dev

# Browser: http://localhost:3000
```
