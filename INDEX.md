## 🚀 The 5-Minute Start

```bash
# 1. Backend
cd backend
python -m venv venv
venv\Scripts\activate  # Windows or source venv/bin/activate
pip install -r requirements.txt
python main.py

# 2. Frontend (new terminal)
cd frontend
npm install
npm run dev

# 3. Browser
Open: http://localhost:3000
```

Done! 🎉
